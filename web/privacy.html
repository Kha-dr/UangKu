Kembali ke KasIn

Terakhir diperbarui: November 2026 · Berlaku untuk aplikasi web KasIn dan KasIn Remote MCP Server.

1. Penyimpanan Lokal (Local-First)

KasIn menyimpan seluruh data keuangan Anda (rekening, transaksi, aset, dan wishlist) secara langsung di perangkat Anda menggunakan SQLite WASM (IndexedDB / OPFS) atau file .sqlite lokal yang Anda pilih melalui File System Access API. Kami tidak mengoperasikan server database terpusat dan tidak pernah mengumpulkan atau membaca catatan keuangan Anda.

2. Sinkronisasi Google Drive (Opsional)

Jika Anda memilih masuk dengan Google, KasIn menggunakan izin https://www.googleapis.com/auth/drive.appdata untuk menyimpan dan menyinkronkan basis data (kasin.sqlite dan delta JSON) di folder tersembunyi khusus aplikasi (appDataFolder) pada Google Drive Anda sendiri.

  • KasIn tidak meminta akses ke file, foto, atau dokumen Google Drive Anda lainnya.
  • Izin userinfo.profile dan userinfo.email hanya digunakan untuk menampilkan nama dan foto profil Anda di menu aplikasi, disimpan lokal di localStorage, dan dihapus saat Anda keluar.
3. Remote MCP Server & WebMCP

Komponen mcp-server bersifat stateless: server hanya meneruskan permintaan terotorisasi antara klien AI (seperti Claude atau Gemini) dan Google Drive appDataFolder Anda di memori sementara selama permintaan berlangsung, tanpa menyimpan token OAuth ataupun salinan basis data di disk server.

4. Kontrol & Penghapusan Data

Anda memegang kendali penuh atas data Anda. Anda dapat mengekspor cadangan .sqlite atau CSV kapan saja dari menu Basis Data, menghapus penyimpanan browser lokal, atau mencabut akses Google Drive melalui halaman Google Account Permissions.
